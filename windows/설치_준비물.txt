Kavis 윈도우 에이전트 빌드 - 준비물 체크리스트 (exe 방식, Qualys와 동일)
=========================================================================

[설치할 프로그램] (윈도우 PC/서버에)

Python 3.11 이상 - 이것 하나만 있으면 됩니다.
   - 다운로드: https://python.org/downloads
   - 설치 화면에서 "Add python.exe to PATH" 반드시 체크


[소스 파일 받는 방법]

git이 있으면:
   git clone https://github.com/Grikko-sec/kavis-agent.git
   cd kavis-agent\windows

git이 없으면:
   https://github.com/Grikko-sec/kavis-agent/tree/main/windows
   여기서 windows 폴더 통째로 다운로드


[빌드 - windows 폴더 안에서, PowerShell "관리자 권한"으로 실행]

   .\build.ps1

   -> dist\kavis-agent-windows.exe 생성됨


[설치 + 예약 작업 등록]

   .\install.ps1

   -> C:\Program Files\Kavis Agent\ 로 설치, 부팅 시 자동 시작 등록


[등록 - 최초 1회, 관리자 PowerShell]

   cd "C:\Program Files\Kavis Agent"
   .\kavis-agent-windows.exe configure --server-url https://<서버주소> --enroll-key <등록키>
   .\kavis-agent-windows.exe collect
   (여기서 "전송 성공 (200)" 뜨면 정상 -> Kavis 웹 자산 목록에 자동 등록됨)

   그 다음 상시 수집 시작:
   Restart-ScheduledTask -TaskName KavisAgent


[제거]

   .\uninstall.ps1


[참고]
- 자세한 설명/문제 해결: windows\README.md
- build.ps1 이나 install.ps1 단계에서 오류 나면 그 메시지 그대로 알려주면
  바로 고쳐드립니다 (리눅스에서는 빌드 검증을 못 해봤음)
